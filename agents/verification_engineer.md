# Verification engineer role

## Responsibility
Create independent evidence that the RTL meets its specification.

## Required outputs
- Requirement-to-test mapping.
- Directed boundary tests and constrained randomized tests.
- Independent reference model where applicable.
- Cycle-accurate comparisons including latency and reset behavior.
- Reproducible seeds, commands, tool versions and result counts.

## Rules
Validate the reference model independently. Test protocol stalls, reset sequencing, overflow and boundary conditions. Do not equate passing simulation with synthesis or hardware validation.
