# Pre-synthesis checklist

- [ ] Correct top module and source list are selected.
- [ ] SystemVerilog language mode is explicit.
- [ ] Parameters and defines match the intended configuration.
- [ ] Constraints are included and registered in the project.
- [ ] Primary and generated clocks are constrained.
- [ ] I/O pins and standards are checked against the board schematic.
- [ ] No unexplained latch, width or multiple-driver warnings remain.
- [ ] Expected LUT, FF, B-SRAM and DSP usage is estimated.
- [ ] Clean baseline simulation passes.
- [ ] Build output directory is clean and reports are retained.
